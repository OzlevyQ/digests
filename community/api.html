בסיס

כל הקריאות הן HTTPS מול כתובת אחת, JSON בשני הכיוונים, ו־CORS פתוח (אפשר לקרוא מכל דפדפן):

BASE = https://kuehljnnpwgzyodjaund.supabase.co/functions/v1/papit-api
  • אין הרשמה ואין חשבונות. קריאות ופידי RSS פתוחים לכולם.
  • כתיבה (פרסום, מחיקה) דורשת מפתח API של חדר, שמתקבל פעם אחת בפתיחת החדר.
  • בשרת נשמר רק גיבוב (SHA-256) של המפתח — איבדתם אותו, אין שחזור; פותחים חדר חדש.
  • גוף בקשה מוגבל ל־64KB.

אימות כתיבה

מעבירים את מפתח החדר באחת משתי דרכים (ערכים לדוגמה בלבד):

x-api-key: papit_000000000000000000000000000000000000000000000000
# או
Authorization: Bearer papit_0000...

חדרים

POST/rooms/:slug/cover — תמונת שער לחדר

דורש מפתח. JPEG/PNG/WebP ב־base64 — שימו לב: שרת ה-edge דוחה גוף בקשה מעל כ-100KB, אז כווצו את התמונה מראש (האתר מכווץ ל-JPEG קטן אוטומטית). נשמר כ־<slug>.png ומוגש מ־Storage ציבורי.

curl -X POST "$BASE/rooms/digests/cover" \
  -H "x-api-key: $KEY" -H "content-type: application/json" \
  -d '{"content_type":"image/png","data":"iVBORw0KG…"}'
{"url":"…/storage/v1/object/public/papit-covers/digests.png"}

POST/rooms — פתיחת חדר

פתוח לכולם. מחזיר את מפתח ה־API פעם אחת בלבד. המייל נשמר פרטית ולא מוצג בשום קריאה.

curl -X POST "$BASE/rooms" \
  -H "content-type: application/json" \
  -d '{"title":"מודלים מקומיים","email":"me@example.com","description":"על מה החדר?"}'
שדהחובהמגבלה
titleכןעד 80 תווים
emailכןפרטי, לא מפורסם
descriptionלאעד 300 תווים
{
  "slug": "room-a1b2c3",
  "api_key": "papit_...",
  "rss": "https://.../papit-api/rss/room-a1b2c3"
}

ה־slug נגזר אוטומטית מהשם. מגבלת קצב: 3 חדרים לשעה ו־10 ליום מכתובת IP.

GET/rooms — ספריית החדרים

curl "$BASE/rooms"
{"rooms":[{"slug":"digests","title":"הדייג'סטים","description":"...",
  "created_at":"2026-11-01T02:25:46.246Z","post_count":89}]}

עד 100 חדרים, מהחדש לישן. לא חושף מפתחות ולא רמזים למפתחות.

GET/rooms/{slug} — חדר ופוסטים

curl "$BASE/rooms/digests"
{"room":{"slug":"digests","title":"הדייג'סטים","description":"...","created_at":"..."},
 "posts":[{"id":"...","title":"...","body":"...","link":"https://...",
           "author_name":"עוז לוי","created_at":"..."}]}

עד 200 הפוסטים האחרונים בחדר, מהחדש לישן.

DELETE/rooms/{slug} — מחיקת חדר

דורש מפתח. מוחק את החדר ואת כל הפוסטים שבו — ללא שחזור.

curl -X DELETE "$BASE/rooms/digests" -H "x-api-key: papit_..."

פוסטים

POST/rooms/{slug}/posts — פרסום פוסט

דורש מפתח של אותו חדר.

curl -X POST "$BASE/rooms/digests/posts" \
  -H "x-api-key: papit_..." \
  -H "content-type: application/json" \
  -d '{"title":"פוסט ראשון","body":"טקסט חופשי","link":"https://example.com","author_name":"עוז"}'
{"id":"c0a80123-..."}
שדהחובהמגבלה
titleכןעד 120 תווים
bodyלאעד 5,000 תווים
linkלאעד 500 תווים, http/https בלבד
author_nameלאעד 60 תווים

מגבלות: 20 פוסטים לשעה ו־100 ליום מכתובת IP, ועד 500 פוסטים בחדר.

DELETE/posts/{id} — מחיקת פוסט

דורש את מפתח החדר שהפוסט שייך לו.

curl -X DELETE "$BASE/posts/c0a80123-..." -H "x-api-key: papit_..."
# {"ok":true}

GET/latest — אחרונים מכל החדרים

curl "$BASE/latest"

20 הפוסטים האחרונים בכל PAPit, כולל room_slug ו־room_title של כל פוסט.

התראות Push

POST/push/subscribe — הרשמה להתראות חדר

curl -X POST "$BASE/push/subscribe" \
  -H "content-type: application/json" \
  -d '{"room_slug":"digests","endpoint":"https://push.service/..."}'

רושם endpoint של Web Push לחדר. על כל פוסט חדש בחדר נשלחת התראה (tickle ללא payload, חתום VAPID; מפתח החדר לא נדרש — ההרשמה פתוחה, והשירות שומר רק את ה־endpoint). endpoint לא תקף (404/410) נמחק אוטומטית.

POST/push/unsubscribe — ביטול התראות

curl -X POST "$BASE/push/unsubscribe" \
  -H "content-type: application/json" \
  -d '{"room_slug":"digests","endpoint":"https://push.service/..."}'

מסיר את ה־endpoint מהחדר. בלי room_slug — מסיר מכל החדרים.

פידי RSS

GET/rss ו־/rss/{slug}

  • GET /rss — פיד גלובלי של כל הפוסטים.
  • GET /rss/{slug} — פיד של חדר אחד, למשל /rss/digests.

RSS 2.0 תקין, 50 הפוסטים האחרונים, cache של 60 שניות. הקישור של הפוסט מופיע כ־link של ה־item וגם בתוך ה־description. מתעדכן מיד עם כל פרסום.

דוגמה מקצה לקצה (JavaScript)

// פתיחת חדר ושמירת המפתח (מוצג פעם אחת!)
const BASE = 'https://kuehljnnpwgzyodjaund.supabase.co/functions/v1/papit-api'
const r = await fetch(`${BASE}/rooms`, {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ title: 'החדר שלי' })
}).then(r => r.json())
localStorage.setItem('papit.key.' + r.slug, r.api_key)

// פרסום פוסט
await fetch(`${BASE}/rooms/${r.slug}/posts`, {
  method: 'POST',
  headers: { 'content-type': 'application/json', 'x-api-key': r.api_key },
  body: JSON.stringify({ title: 'היי', body: 'הפוסט הראשון שלי' })
})

בדיוק ככה האתר הזה עובד — אותו API, אותם מפתחות, בלי שרת ביניים.
